# Run List

Useful columns/filters:

- Run ID / name,
- workflow + revision,
- namespace / caller,
- state,
- created/start/end time,
- duration,
- active/failed/retrying task counts,
- redrive count,
- tags,
- parent run (if subworkflow).

Filters should support state, namespace, workflow revision, time range, caller, failure class, and redriven runs.
