# Proposed Post-Gate Milestones

## Phase 1A — Semantic kernel

Contracts, state machine, validation, dependency evaluator, deterministic conformance tests.

## Phase 1B — Durable single-cluster control plane

Persistence, event journal, reconciliation, timers, API, reference execution adapter.

## Phase 1C — Operational product

Run UI, task/attempt debugging, cancel/suspend/redrive, RBAC/audit.

## Phase 1D — Scale and HA

Horizontal reconciler scaling, partitioning, backpressure, fault injection, performance SLOs.

## Phase 2 — Advanced workflow constructs

Dynamic expansion, subworkflows, event waits, richer scoped finalization, caching/memoization if justified.
